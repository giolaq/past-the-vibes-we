# Vega Lifecycle Fixture

Use `../vega-lifecycle.json` if the Vega SDK or VDA is unavailable.

The fixture supplies recorded results for eight lifecycle operations:

1. SDK.
2. Device.
3. Build.
4. Install.
5. Start.
6. Initial running-state sample.
7. Logs.
8. Post-dwell running-state sample.

The fixture proves lifecycle control and report format. It does not prove that
an app passed on a live device or rendered the intended interface.
